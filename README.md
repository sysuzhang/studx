# 汉字学习平台（首页 + 分级练习 + 字帖工坊）

一个纯前端汉字学习平台，包含：

- 大气美观的首页
- 分级汉字练习（按“年龄段 + 汉语级别”双维筛选）
- 词典解释、常用词组、成语故事
- 笔顺动画与笔画顺序
- 字帖打印工坊（田字格/米字格/回宫格）

## 核心功能

### 1) 首页（`index.html`）

- 平台级视觉设计（Hero、功能卡、学习路径）
- 快速入口：分级练习 / 字帖工坊

### 2) 分级练习（`practice.html`）

- 年龄段：6-8 / 9-12 / 13-16 / 16+
- 汉语级别：启蒙 / HSK1 / HSK2 / HSK3 / HSK4+
- 双维筛选汉字学习清单
- 每个汉字提供：
  - 拼音与词典释义
  - 常用词组
  - 关联成语 + 成语故事
  - 笔顺动画 + 笔画顺序列表
- 一键将清单导入字帖工坊

### 3) 字帖工坊（`worksheet.html`）

- 自动过滤输入中的非汉字字符
- 格子模板：田字格 / 米字格 / 回宫格
- 练习模式：描红 / 空白临写
- 可配置每字格数、每行格数、格子尺寸
- A4 打印样式优化

## 本地使用

该项目为静态网页，无需构建。

### 方式 1：直接打开

直接打开 `index.html`，再从首页进入具体功能页。

### 方式 2：本地静态服务器（推荐）

```bash
python3 -m http.server 8080
```

然后访问：`http://localhost:8080`

## 使用路径

1. 打开首页，进入 **分级练习**
2. 选择年龄与级别，生成学习清单
3. 点击汉字卡片，查看释义、词组、成语故事与笔顺
4. 点击“将当前清单用于字帖打印”，跳转到 **字帖工坊**
5. 配置格子参数并打印练习

> 打印时建议勾选“背景图形”，以保留辅助线。

## 技术实现

- UI：原生 HTML + CSS + JavaScript
- 笔顺动画：`hanzi-writer`（CDN）
- 笔画数据：`hanzi-writer-data`（CDN）
- 学习字库：本地静态数据 `hanzi-data.js`
