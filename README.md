# 汉字字帖打印网站（含笔顺演示）

一个轻量级纯前端网站，用于快速生成可打印的汉字字帖，并支持汉字笔顺动画演示与笔画顺序查看。

## 功能特性

- 输入任意汉字文本，自动过滤非汉字字符
- 支持 3 种格子模板：
  - 田字格
  - 米字格
  - 回宫格
- 支持描红 / 空白临写两种练习模式
- 可配置每字练习格数、每行格子数、格子尺寸
- 内置笔顺演示（Hanzi Writer）
- 展示笔画顺序列表（按第 1 笔、第 2 笔...）
- A4 打印样式优化

## 本地使用

该项目为静态网页，无需构建。

### 方式 1：直接打开

直接双击 `index.html` 即可使用。

### 方式 2：本地静态服务器（推荐）

```bash
python3 -m http.server 8080
```

然后访问：`http://localhost:8080`

## 使用说明

1. 在左侧输入要练习的汉字
2. 配置字帖参数（格子类型、练习格数、描红模式等）
3. 点击 **生成字帖**
4. 在“选择演示汉字”中点击任意字，查看笔顺动画和笔画顺序
5. 点击 **打印字帖**，进入浏览器打印

> 打印时建议勾选“背景图形”，以保留字帖辅助线。

## 技术说明

- UI：原生 HTML + CSS + JavaScript
- 笔顺动画：`hanzi-writer`（CDN）
- 笔画数据：`hanzi-writer-data`（CDN）
