# 汉字学习平台（首页 + 分级练习 + 拼音频道 + 打字闯关 + 键盘练习 + 学习日历 + 汉字总览 + 新华字典 + 订阅中心 + 登录体系 + 教师端 + 用户中心 + 字帖工坊）

一个“前端 + 轻量 Node 云端服务”汉字学习平台，包含：

- 大气美观的首页
- 分级汉字练习（按“年龄段 + 汉语级别”双维筛选）
- 拼音教学频道（声母/韵母/声调/拼读）
- 游戏化打字闯关（汉字输入 / 拼音输入，独立页面）
- 键盘操作练习（飞机空战键位游戏，独立页面）
- 学习日历（艾宾浩斯复习法）
- 汉字总览（一览全体汉字与覆盖情况）
- 新华字典频道（教学版词条检索）
- 小学语文课本频道（1-6 年级）
- 订阅中心（基础免费 + 进阶订阅）
- 登录体系（多用户）
- 云端同步进度（上传/下载）
- 教师端（学生学习报告）
- 用户中心（学习进度、学习评价、个性化建议）
- 词典解释、常用词组、成语故事
- 笔顺动画与笔画顺序
- 字帖打印工坊（田字格/米字格/回宫格）
- 数学数字字帖（数字与算式书写）
- 年龄分级字帖本（可整本打印）与扫描复盘循环生成

## 核心功能

### 1) 首页（`index.html`）

- 平台级视觉设计（Hero、功能卡、学习路径）
- 快速入口：分级练习 / 拼音频道 / 打字闯关 / 键盘练习 / 学习日历 / 汉字总览 / 新华字典 / 订阅中心 / 用户中心 / 字帖工坊

### 2) 分级练习（`practice.html`）

- 年龄段：6-8 / 9-12 / 13-16 / 16+
- 汉语级别：启蒙 / HSK1 / HSK2 / HSK3 / HSK4+
- 双维筛选汉字学习清单
- 每个汉字提供：
  - 拼音与词典释义
  - 拼音标注开关（汉字卡片、词组、成语支持拼音注音）
  - 汉字读音按钮（当前字、词组、成语可听）
  - 跟读对比（网页直接朗读，识别结果与标准读音对比）
  - 一键加入字帖收藏（学习中可累积到字帖工坊）
  - 常用词组
  - 象形文字图案（优先古文字字形，含来源链接）
  - 关联成语 + 成语故事
  - 笔顺动画 + 笔画顺序列表
- 一键将清单导入字帖工坊

### 3) 拼音教学频道（`pinyin.html`）

- 声母教学（发音提示 + 示例词）
- 韵母教学（单韵母/复韵母/鼻韵母）
- 声调教学（调值与示例）
- 拼读训练器（声母 + 韵母 + 声调组合）
- 示例发音播放（浏览器语音）

### 4) 打字闯关（`typing.html`）

- 支持两种模式：汉字打字 / 拼音打字
- 游戏化机制：计时、连击积分、生命值、跳过扣血
- 级别筛选：全部 / 启蒙与 HSK1 / HSK2-3 / HSK4+
- 可选择是否包含词组题，兼顾基础与进阶输入能力
- 自动记录战绩（分数、命中率、连击峰值）
- 一键将本局错题汉字加入“字帖收藏夹”
- 中间闯关区放大显示，输入实时判定正确性
- 自动滚动“待输入练习流”，输入正确后自动切题
- 趣味任务系统（连击/命中/命中率挑战）
- 赛季制（周赛 / 月赛）与赛季称号（如“连胜王”“Boss猎手”）
- 本地排行榜支持筛选：今日 / 本周 / 历史

### 5) 键盘练习（`keyboard.html`）

- 与打字闯关拆分为独立页面，突出键位训练主线
- 飞机空战玩法：障碍物从上到下掉落，按下已出现字符即可发射对应子弹击碎目标
- 三种字母池：基础键位 / 拼音字母 / 全字母
- 三关卡：初级 / 中级 / 高级（不同刷怪速度、加分与扣分规则）
- 放大中间空战区，动态匹配按键并自动滚动“当前可击打按键”
- 特殊目标：加分目标 / 时间补给 / 生命补给 / 减速装置 / 装甲目标
- 趣味任务 + 每日键位任务（目标命中/命中率/速度）与任务配置一键应用
- 记录积分、速度、连击峰值并写入用户中心统计

### 6) 学习日历（`calendar.html`）

- 按艾宾浩斯复习间隔自动排程：`0/1/2/4/7/15/30` 天
- 支持设置开始日期、计划天数、每日新字数
- 支持“初学者推荐字”一键填充
- 支持从分级练习页一键导入当前汉字清单
- 每日任务支持勾选完成并持久化（本地存储）
- 支持“仅看未完成任务”筛选
- 每日任务可一键“入字帖”

### 7) 汉字总览（`overview.html`）

- 全体汉字一览表（表格化查看）
- 支持按关键词、年龄段、汉语级别筛选
- 支持按词组数/成语数排序
- 可筛选“含成语”“含象形图”“学习日历已打卡”
- 展示每个汉字的详情（释义、词组、成语、象形图、学习状态）
- 可一键跳转到分级练习、学习日历、新华字典或加入字帖

### 8) 新华字典（`xinhua.html`）

- 独立“教学版新华字典”频道，支持字/音/义检索
- 可按部首、级别筛选，可筛选含成语、含象形图词条
- 词条内容包含：拼音、部首、笔画、结构、基本释义、组词、成语、例句
- 支持词条朗读、加入字帖、跳转练习/日历
- 与汉字总览联动：总览表与详情可一键“查字典”

### 9) 小学语文课本（`textbook.html`）

- 覆盖小学 1-6 年级语文课本学习主题（按年级 + 学期切换）
- 课文目录检索：支持按标题/关键词/生字快速定位
- 课文学习卡：课文内容、生字、重点词语、思考题、学习任务
- 朗读功能：可一键朗读课文内容
- 学习进度：支持“本课已掌握”标记与任务勾选持久化
- 与字帖工坊联动：本课生字一键加入字帖收藏并跳转打印

### 10) 用户中心（`user.html`）

- 学习者档案（母语、目标等级、学习目标、日学习时长）
- 学习进度总览（已打卡汉字、任务完成、连续学习、跟读准确率、打字闯关统计、键位练习统计、键位日任务统计）
- 学习评价与改进建议（面向外国学习者）
- 显示当前套餐与今日配额（打印次数 / 字典检索次数 / 进阶关卡解锁状态）
- 云端同步面板（登录态、上传云端、下载本地、同步状态）
- 字帖收藏夹管理（移除/清空/直接进入字帖打印）
- 最近学习活动记录（入字帖、跟读、打字闯关、键位练习、每日键位任务、打卡、档案更新、套餐变更）

### 11) 订阅中心（`pricing.html`）

- 商业模式：基础能力免费，进阶能力按月/按年订阅
- 套餐对比：打印额度、检索额度、键盘高级关卡、字典进阶释义、支持服务
- 当前套餐看板：显示当日配额消耗
- 真实支付闭环（Stripe）：创建订单 → 跳转支付 → 服务端 Webhook 验签 → 订单状态回写 → 套餐自动生效
- 订单状态同步：支持支付回跳后主动轮询订单状态，避免仅依赖前端回跳导致状态不一致
- 支付通道扩展位：已预留微信/支付宝接入入口（当前待配置）

### 12) 登录体系（`auth.html` + `cloud-sync.js`）

- 支持多用户注册与登录（学生/教师）
- 登录后自动保存会话状态
- 教师账号支持教师邀请码注册或默认教师种子账号

### 13) 教师端（`teacher.html`）

- 查看学生列表与最近同步时间
- 查看学生关键学习指标（已学汉字、打字、键盘、跟读、活动）
- 查看学生近期学习活动（来自云端同步快照）

### 14) 字帖工坊（`worksheet.html`）

- 自动过滤输入中的非汉字字符
- 支持“汉字字帖 / 数学数字字帖”双模式
- 数学模式支持数字与运算符：`0-9`、`+ - × ÷ = ( ) % .`
- 格子模板：田字格 / 米字格 / 回宫格
- 练习模式：描红 / 空白临写
- 可配置每字格数、每行格数、格子尺寸
- 支持“字帖收藏字”一键导入/追加/清空
- 可朗读当前练习汉字（浏览器语音）
- 支持当前汉字跟读识别与对比反馈
- 支持将当前练习字加入字帖收藏
- 套餐分层：基础版每日打印 2 次，进阶版不限量
- 新增“出版式字帖本”能力：按年龄段 + 分级自动成册，一次打印为整本训练册
- 支持扫描/OCR结果复盘：按“汉字 + 分数”批量导入，自动判定达标与未达标
- 支持循环再生成：自动将未达标汉字标记并优先纳入下一册强化字帖
- A4 打印样式优化

## 本地使用

该项目包含 Node 云端服务（登录/同步/教师报告）。

### 方式 1：启动完整服务（推荐）

```bash
npm install
npm run dev
```

访问：`http://localhost:8787`

> 该方式同时提供网页静态资源和 `/api/*` 云端接口（登录/同步/教师端）。

#### 如需启用真实支付（Stripe）

1) 复制环境变量模板并填写 Stripe 密钥：

```bash
cp .env.example .env
```

2) 启动服务（可通过 shell 导出变量，或使用你习惯的方式注入 `.env`）：

```bash
APP_BASE_URL=http://localhost:8787 \
STRIPE_SECRET_KEY=sk_test_xxx \
STRIPE_PUBLISHABLE_KEY=pk_test_xxx \
STRIPE_WEBHOOK_SECRET=whsec_xxx \
npm run dev
```

3) 本地转发 Stripe Webhook 到服务端（需安装 Stripe CLI）：

```bash
stripe listen --forward-to localhost:8787/api/payments/stripe/webhook
```

### 方式 2：仅静态浏览（不含登录/云同步）

```bash
python3 -m http.server 8080
```

然后访问：`http://localhost:8080`

> 注意：此方式无法使用登录体系、云端同步和教师端报告。

## 使用路径

1. 打开首页，先进入 **拼音频道** 练习发音基础
2. 再进入 **分级练习**，选择年龄与级别生成学习清单
3. 在学习过程中，把重点汉字“加入字帖收藏”
4. 先进入 **键盘练习**，完成键位热身与每日任务
5. 再进入 **打字闯关**，进行汉字/拼音输入强化并回收错题
6. 点击“将当前清单纳入学习日历”，自动生成艾宾浩斯复习计划
7. 在“汉字总览”查看整体字库覆盖与学习进度，并可跳转字典查询
8. 在“小学语文课本”按年级学期完成课文、生字词和任务练习
9. 在“新华字典”检索生字，补全部首/笔画/用法理解
10. 在“订阅中心”按学习频率选择套餐（基础免费，进阶按需）
11. 在“用户中心”查看学习评价、配额与个性化建议
12. 最后进入 **字帖工坊**，使用收藏字生成字帖并打印

> 打印时建议勾选“背景图形”，以保留辅助线。

## 技术实现

- UI：原生 HTML + CSS + JavaScript
- 轻量后端：Node.js + Express（`cloud-server.js`）
- 支付：Stripe Checkout + 服务端 Webhook 验签（`stripe` SDK）
- 笔顺动画：`hanzi-writer`（CDN）
- 笔画数据：`hanzi-writer-data`（CDN）
- 学习字库：本地静态数据 `hanzi-data.js`
- 字典词条：`xinhua-data.js`（基于平台字库扩展的教学版词典数据）
- 象形图案图片：Wikimedia Commons（公开古文字/字形资源）
- 本地学习存储：`localStorage`（学习日历、跟读记录、打字战绩、键位练习记录、每日键位任务、用户档案、字帖收藏、订阅套餐与配额）
- 云端同步：`cloud-server.js` 提供注册/登录、进度上传下载、教师报告 API
